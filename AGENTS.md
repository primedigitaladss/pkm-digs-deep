# PKM Open Well Contractor - Agent Guidelines

PKM Open Well Contractor is a modern, high-converting, mobile-first website for heavy machinery open-well digging and excavation services across Tamil Nadu.

## Development Workflow
- Keep components modular and typed with TypeScript.
- Follow Tailwind CSS industrial theme guidelines defined in `src/styles.css`.
- Ensure all CTA phone and WhatsApp enquiry buttons remain functional.
